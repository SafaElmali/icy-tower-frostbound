# Frostbound

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product Purpose

An Icy Tower-inspired browser game: build momentum, chain jumps, and climb a frozen cathedral. The homepage is the playable game's launch screen.

## Users

Players starting or retrying solo climbs and friends joining 2–4-player races. Keyboard and touch input are supported. More detailed audience demographics have not been established.

## Capabilities and Constraints

Classic, Party, and Practice modes; daily shared towers; multiplayer lobbies; outfits; personal progress; rankings; help; sound, motion, and graphics settings. Existing callbacks, invitations, loading/error states, saved records, and input behavior must remain functional. Three.js renders the live tower; WebGL is required. The current stack is React/Vinext with CSS modules. The static export deploys to Netlify.

## Brand Commitments

Name: Icy Tower — Frostbound. Existing cathedral and climber are real game assets. The homepage redesign is authorized; gameplay and other feature surfaces retain their current presentation. Design choices are delegated to the assistant by the user's working agreements.

## Evidence on Hand

Current code and local running game; README and gameplay/development documentation; existing art and character assets. No testimonials, commercial statistics, or online player counts are supplied.

## Product Principles

- Let players start a climb immediately.
- Make multiplayer, daily challenges, and personal progression discoverable.
- Preserve keyboard/touch access and recoverable navigation.
- Represent actual game modes and stored progress accurately.
