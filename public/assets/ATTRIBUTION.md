# Frostbound assets

The cathedral environment artwork was created specifically for this game using OpenAI image generation. The expedition climber was modeled for this project in Blender; the editable source and generation script are included in `scripts/`. No assets from the original Icy Tower game are used.

Three.js is distributed under the MIT License. Its procedural RoomEnvironment supplies reflected lighting, and its postprocessing and geometry utilities are used by the renderer. UI icons are from Lucide under the ISC License.
