# Frostbound assets

The cathedral environment artwork was created specifically for this game using OpenAI image generation. The Harold model was created for this project in Blender, based on the original Icy Tower character design from Free Lunch Design; the editable source and generation script are included in `scripts/`. No game files were extracted. This is an unofficial fan recreation of the character. Reference: https://www.mobygames.com/game/27688/icy-tower/

Three.js is distributed under the MIT License. Its procedural RoomEnvironment supplies reflected lighting, and its postprocessing and geometry utilities are used by the renderer. UI icons are from Lucide under the ISC License.
