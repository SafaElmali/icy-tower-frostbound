# Settings panel

Mode: Operate

THESIS: Make the four game preferences easy to understand and change.

OWN-WORLD: Extend the frozen arcade menu with the shared condensed display face, navy surfaces, ice switches, and restrained peach feedback.

STORY: Adjust audio, then motion and graphics, optionally enter fullscreen, and return to the title or paused climb.

FIRST VIEWPORT: Two grouped columns on desktop: Audio and Feel & detail. Each control has descriptive copy, a native accessible switch, and an explicit visible state. Fullscreen sits below as its own action. On phones the groups become compact flat sections so all four controls are visible without scrolling through large cards.

FORM: Two groups chosen autonomously over a category sidebar or a control grid. The existing menu tabs and footer remain. Music stays independently configurable when sound is muted; its status and explanatory text make that relationship clear. Fullscreen button text follows actual fullscreen state through the browser event. No new comp or visual-world workshop for this scoped extension.

Verification: Label activation, keyboard Space, sound/music dependency, motion/quality changes, actual fullscreen entry/exit, 1440×900, 687×843, 390×844. Restore user preferences after checks.
